ROVERLOOM / EXPERIMENTAL RACE

Build a rover. Race it on Mars.

Choose a mode, set up your six-wheeler, pick a course, then start the race on this Mac. Your finished runs go on the local leaderboard and come back as ghosts.

Save the rover file, then run the command from the repository root in Terminal. The game window opens; click it once to drive.


    

    
WS driveAD turnSpace boostC cameraR rescue (+30 s)

    
Boost pads on the track give one boost. Sand slows all-round tires. The supply pad recharges the battery. Dust storms slow everyone; the scout sensor warns earlier.
