# 0013: UE 5.8.4 with Xcode 27.2 on macOS 27

Status: Accepted by the owner (2026-11-03), for the limited scope below

**Scope of acceptance:** use UE 5.8.4 as Roverloom's Unreal development base. This record does not establish Epic's support for macOS 27 or Xcode 27,
long-term stability, performance on realistic Mars terrain, or distribution to other machines or operating systems. None of these has been verified.

## Context

[ADR 0003](0003-unreal-engine-5-8.md) chose UE 5.8 and official MCP, to be accepted once the engine ran and MCP verification passed.
[ADR 0012](0012-m4-mac-for-unreal.md) chose an Apple M4 Mac. Epic's requirements page lists neither macOS 27 nor Xcode 27, and recommends Xcode 26.1.1.
Apple's table lists Xcode 26 up to macOS 26.x, and Xcode 27 for macOS 26.6 or later.

A disposable project outside this repository measured this combination. The numbers and limits are in the
[checklist](../macos-checklist.md#unreal-results-on-this-mac) and in [Unreal MCP](../unreal-mcp.md#measured-results).

## Decision

- Use UE 5.8.4 from the Launcher, Xcode 27.2, and the Metal Toolchain on macOS 27.0.1, and do not update any of them during a step without recording it.
- Accept ADR 0003's engine choice for this machine. Official MCP remains experimental. It is verified on this Mac for reads in `unreal/`, and for edits and saves only in the disposable project.
- Do not edit `Apple_SDK.json` or any other engine file.
- Use `-package` for every Mac packaging run, and run the resulting `.app`. A successful exit code alone is not evidence.
- Stop work if the editor crashes again, or free memory falls below 10%. Record the crash before retrying.
- In `unreal/`, enable `EditorToolset` rather than All Toolsets, and limit it and `ModelContextProtocol` to the editor target. Add other toolsets when a task needs them.
- Disable `AndroidFileServer` in `unreal/`, because it writes a changing `SecurityToken` to a tracked file on every editor start. iOS and Android are not targets. If they become targets, decide again in a new record, and keep the token out of Git.
- Commit `DefaultInput.ini` with only its two class settings, so that the editor does not generate one.

## Consequences

- The combination is measured, and is not supported by Epic in writing. An update of any part needs a new check.
- 16 GB is Epic's minimum. Large terrain and `Capture` quality are unmeasured, and may need another machine, by the owner's decision.
- One editor crash remains unexplained.
- Builds are signed ad hoc, so distributing them to other Macs is unverified, and may need the paid Apple Developer Program.
- macOS stays out of CI, so these results are recorded by hand.
- Android File Server is unavailable in `unreal/` until this is reconsidered.
- UE Trace listens on all interfaces in the Development build, and this is an [open security issue](../security.md#unresolved). Nothing was changed for it. Decide before distribution or public release.
- Whether the owner has accepted the current EULA is the owner's record, and is not stated here.
