# Assets and sources

A register of everything not written by this project, plus planned data. Update it in the same
pull request that adds an asset. See [licensing review](licensing-review.md).

## In this repository

| Item | Source | License | Notes |
| --- | --- | --- | --- |
| Code, schemas, scenarios | This project | Not yet selected | All rights reserved until chosen |
| `rovers/standard_6w.json`, `rovers/designs/*` | Original | `NOASSERTION` in provenance; not yet selected | Game values, not based on real vehicles |
| `scenarios/terrains/*` | Generated by procedural rules | Not yet selected | Not real places |
| `docs/images/*` | Screenshots of this project | Not yet selected | Generated terrain only |
| `scripts/blender/build_rover.py` and the rover meshes it writes | Original, built from primitives by the script | Not yet selected | No third-party geometry or textures. Not a replica of any real rover |
| `scripts/vork/rover_concept.py` and the scenes it writes | Original; vork shapes and programs, no third-party assets | Not yet selected | vork is a local tool under its own preview license, never committed. See [ADR 0015](decisions/0015-vork-for-concept-renders.md) |

The repository contains no Epic, Fab, NASA, or USGS assets or data files today.

## Python dependencies

Runtime: `jsonschema` and its dependencies. Development: `pytest`, `ruff`, `mypy`,
`types-jsonschema`. Exact versions are in `python/uv.lock`. **A dependency license audit has not
been performed yet**, and must be done before public release.
